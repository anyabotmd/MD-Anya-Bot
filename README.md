# 🌸 Anya Bot Alpha V0.1

Bot de WhatsApp modular em Node.js + Baileys, com personalidade inspirada em Anya Forger.

## Instalação

```bash
npm install
cp .env.example .env
npm start
```

Escaneie o QR exibido no terminal. A sessão fica em `data/auth` e não deve ser versionada.

## Prefixo

`.` por padrão. Pode ser alterado por grupo com `.prefix <novo>`.

## Sistemas

Menus, Arcade, economia/Mendoins, empregos, pets, RPG social, relacionamentos, XP, conquistas, presentes, casas, mercado, rankings, AFK e administração.

## Segurança

Cooldowns, validações, transações SQLite, proteção contra saldo negativo e verificações de administrador/bot. Não coloque credenciais no GitHub.
